# Werewolf Assets

Struktur ini memisahkan file berdasarkan tanggung jawab:

- `css/base.css`: token desain, reset, font, dan variabel global.
- `css/layout.css`: layout utama moderator, grid, tab, form, dan navigasi.
- `css/components.css`: komponen reusable seperti kartu, tombol, badge, modal, dan panel role.
- `css/overlays.css`: overlay, toast, transisi fase, sheet, dan FAB.
- `css/player.css`: tampilan mode gateway dan player console.
- `css/polish.css`: lapisan visual tambahan.
- `css/theme.css`: tema visual tactical dark.
- `js/core/`: state global, konfigurasi Firebase, boot mode, dan definisi role.
- `js/moderator/`: alur setup, game moderator, aksi malam/siang, dan UI moderator.
- `js/player/`: logic player console.
- `js/polish/`: enhancement visual seperti ikon Lucide, pembersihan emoji, dan sinkronisasi interface.
