      Alur Permainan

      1. Setup: Tambahkan pemain dan siapkan room
      2. Distribusi Role: Atur komposisi role, acak role, lalu mulai game
      3. Malam: Setiap role beraksi secara berurutan
      4. Pagi: Umumkan kematian malam sebelumnya
      5. Siang: Diskusi dan voting pengusiran
      6. Ulangi hingga satu tim menang

      Urutan Aksi Malam

      Thief → Troublemaker → Cupid → Mason 1 → Mason 2 → Doppelganger → White Wolf → Werewolf/Wolfman → Alpha Wolf → Infector → Seer/Apprentice Seer → Aura Seer → Sorcerer → Tracker → Guardian → Bodyguard → Tavern Keeper → Arsonist → Witch → Veteran → Wizard → Gravedigger → Amnesiac → Cult Leader → Vampire → Serial Killer → Little Girl. Wolfman ikut aksi kawanan Werewolf, tetapi terlihat seperti warga biasa oleh role investigasi.

      Tips

      • Gunakan tab "Aksi Malam" untuk memandu setiap role
      • Log permainan otomatis mencatat semua aksi
      • Data otomatis tersimpan di browser (aman jika refresh)
      • Klik pada pemain untuk melihat detail
